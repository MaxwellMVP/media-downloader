Media Downloader v0.3 — Windows 10/11 x64

Розпакуйте ZIP і запустіть MediaDownloader.exe. Встановлювати Python не потрібно.
Папку licenses та файли LICENSE і THIRD_PARTY_NOTICES.md слід зберігати поруч.

Вставте посилання, виберіть MP4 або MP3 і натисніть «Завантажити».
Файли зберігаються в Downloads поточного користувача або у вибрану через
налаштування папку. Історія показує лише завантаження поточного запуску.

Spotify завантажується через пошук відповідного аудіо на YouTube.
Доступність матеріалів залежить від мережі та обмежень сервісів.
