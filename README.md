# Media Downloader v0.3

Windows-застосунок для завантаження відео та музики з **YouTube, TikTok і Spotify**.
Темний інтерфейс українською, формати MP4 / MP3, прогрес і компактні мініатюри.

## Завантаження й запуск

Готові файли публікуються у вкладці **Releases** цього репозиторію:

[Інсталятор v0.3](https://github.com/MaxwellMVP/media-downloader/releases/download/v0.3/MediaDownloader-v0.3-Setup.exe)
· [Portable v0.3](https://github.com/MaxwellMVP/media-downloader/releases/download/v0.3/MediaDownloader-v0.3-Portable.zip)
· [Усі релізи](https://github.com/MaxwellMVP/media-downloader/releases)

| Варіант | Файл | Як запустити |
|---|---|---|
| Зі встановленням | `MediaDownloader-v0.3-Setup.exe` | Запустити майстер встановлення |
| Без встановлення | `MediaDownloader-v0.3-Portable.zip` | Розпакувати ZIP і запустити `MediaDownloader.exe` |

Потрібні **Windows 10/11 x64** і **Microsoft Edge WebView2 Runtime** (зазвичай уже встановлений; інакше завантаж його з сайту Microsoft). Python та допоміжні програми вже входять до EXE.
Інсталятор працює для поточного користувача без прав адміністратора, додає ярлик
до меню «Пуск» і підтримує видалення через налаштування Windows. Ярлик робочого
столу можна вибрати під час встановлення.

## Як користуватися

1. Встав посилання на YouTube, TikTok або Spotify.
2. Вибери «Відео MP4» або «Музика MP3». Для Spotify використовується MP3.
3. Натисни «Завантажити» й дочекайся завершення.
4. Натисни картку для відтворення або іконку папки для показу файлу у Провіднику.

Одночасно виконується одне завантаження. `Tab` / `Shift+Tab` переміщують фокус;
`Enter` і `Space` активують кнопку. Папку можна змінити через ⚙.

Готові збірки зберігають файли в системну папку **Downloads** поточного користувача
або у вибрану папку. Запуск із Python використовує проєктну папку `Downloads/`.
Історія показує **лише поточну сесію**: після нового запуску вона порожня,
а самі збережені файли залишаються на диску. Видалення програми їх не видаляє.

Мініатюри готуються у фоновому потоці. За відсутності обкладинки доступна заглушка.
TikTok-файли спочатку готуються в тимчасовій папці; збіги назв отримують суфікс,
а помилки конвертації показуються в статусі.

## Обмеження

- Spotify не надає аудіо напряму: spotDL шукає відповідний запис на YouTube.
- Доступність, якість і обмеження за IP залежать від зовнішніх сервісів.
- Фото-пости TikTok використовують сторонній API tikwm.com (https://www.tikwm.com/api/): URL допису надсилається цьому сервісу, а його політика конфіденційності не контролюється цим проєктом. У MP3-режимі зберігається лише аудіо.
- Підтримуються посилання `http://` та `https://`.

## Запуск із вихідного коду

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe app.py
```

Спочатку додай допоміжні EXE до `build_bin/`: [перелік і джерела](build_bin/README.md).
Вони не зберігаються в Git. Без них GUI відкриється, але завантаження не працюватиме.
